# 🧴 A simple printed sensor housing

A lift-out sensor cartridge in a perforated housing, styled on the R3 sensor well, for the pH, EC, turbidity and DS18B20 temperature probes.

| File | What |
|---|---|
| [`CAD/SH_SensorHousing_Master.SLDPRT`](CAD) | one multibody SOLIDWORKS part; every size is driven from Tools › Equations |
| [`DOCS/SH_Assembly_Print_Notes.md`](DOCS/SH_Assembly_Print_Notes.md) | measure the probes first, print settings (PETG), assembly |
| [`DOCS/SH_BOM.csv`](DOCS/SH_BOM.csv), [`DOCS/SH_Sensor_Measurement_Sheet.csv`](DOCS/SH_Sensor_Measurement_Sheet.csv) | parts list and the sheet to fill with caliper measurements |

The probe sizes in the model are placeholders until we measure the real probes.
