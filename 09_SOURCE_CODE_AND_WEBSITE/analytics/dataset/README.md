# Synthetic river water-quality dataset

> **Synthetic, not field data.** `synthetic_river_timeseries.csv` is generated by
> [`generate_water_quality_timeseries.py`](generate_water_quality_timeseries.py) (`random.seed(42)`, so it regenerates
> identically). It exists to exercise the decision logic before a permitted river deployment. Cite it as a synthetic
> benchmark wherever it is used.

## 1. What it simulates

30 days of 15-minute readings (2,880 rows), from 2026-03-01 00:00 to 2026-03-30 23:45, with values typical of a lowland
river in Maharashtra:

| Parameter | Baseline model | Normal range in the file |
|---|---|---|
| Water temperature | 24.0 °C ± 3.2 °C daily sine (peak 14:00) + noise σ 0.25 | 20.1–27.9 °C |
| Dissolved oxygen | 7.2 mg/L ± 1.2 mg/L daily sine (photosynthesis by day, respiration by night) + noise σ 0.18 | 5.6–8.8 mg/L |
| pH | 7.45 ± 0.15 daily sine + noise σ 0.05 | 7.15–7.75 |
| Electrical conductivity | 310 µS/cm + noise σ 8 (no daily cycle) | 282–340 µS/cm |
| Turbidity | 8.5 NTU + noise σ 1.2 (no daily cycle) | 4.7–12.9 NTU |
| Depth (river stage) | 1.65 m ± 0.15 m, 4-day sine + noise σ 0.02 | 1.45–1.85 m |
| Flow velocity | 0.72 m/s, following depth, + noise σ 0.015 | 0.66–0.78 m/s |

Not simulated: sensor drift, biofouling, spikes, dropouts, missing data, rain pulses, seasonal change or autocorrelated
noise. The dataset therefore cannot show the real false-alarm rate.

## 2. Injected events

Four events, each shaped as a half-sine, so the first labelled row of each event is not yet perturbed:

| # | Type (`anomaly_type`) | Start | Rows | Peak change |
|---|---|---|---|---|
| 1 | `INDUSTRIAL_ACID_DUMP` | 2026-03-06 02:00 (row 488) | 13 | pH −3.4 (to ≈ 3.9), EC +1,550, turbidity +65, DO −1.8 |
| 2 | `RAW_SEWAGE_OVERFLOW` | 2026-03-13 19:30 (row 1230) | 17 | DO −5.1 (to ≈ 1.5 mg/L), turbidity +175, EC +520, pH −0.6 |
| 3 | `CHEMICAL_SALT_SPILL` | 2026-03-21 11:00 (row 1964) | 13 | EC +2,100 (to ≈ 2,400 µS/cm), pH +1.4, turbidity +40 |
| 4 | `HEAVY_SILT_SURGE` | 2026-03-27 07:00 (row 2524) | 21 | turbidity +290, depth +0.45 m, flow +0.28 m/s, EC −60, DO −1.2 |

The events are tens to hundreds of times larger than the noise, so detecting them is easy. Event 4 is natural runoff
labelled as contamination; a deployed system that alarms on monsoon silt would alarm often, which is why the river level
is logged alongside.
