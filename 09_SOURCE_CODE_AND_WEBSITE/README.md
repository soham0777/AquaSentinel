# Source code and tools

| Folder | What it is |
|---|---|
| `mechanical/src` | Python generator of the R3 CAD, drawings and the 14 design checks (`build.py`, `params.py`). Its outputs are published in `01_DESIGN_CAD_AND_DRAWINGS`. |
| `mechanical/tools`, `mechanical/viewer` | STEP checker, drawing screenshots, 3D viewer template |
| `analytics` | decision logic (`detector.py`), the synthetic-data benchmark (`evaluate.py`), the plume model and the dataset |
| `project-management` | ENOVIA plan (Gantt, summary) |

The firmware lives in `06_ELECTRONICS_AND_FIRMWARE/firmware` and the website in `docs/` (GitHub Pages).
