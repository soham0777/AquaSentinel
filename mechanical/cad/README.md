# mechanical/cad: generated CAD data

| Path | Contents |
|---|---|
| `BOM_R3.csv` | bill of materials: 66 line items, 144 pieces, part number, material, process, mass, basis, CAD file. Every cost cell still says `TO QUOTE` |
| `parts/` | one STEP + one STL per part (66 + 66), named `AS3-nnn_Description` |
| `assembly/` | `AquaSentinel_R3_Assembly_MidWater.step` and `AquaSentinel_R3.glb` (used by the web viewer). Low- and high-water variants are regenerated by `build.py` and not stored |

All of it is **generated** by `python mechanical/src/build.py`; edit `mechanical/src/params.py`, not these files.
The SOLIDWORKS-native version is in [`../solidworks`](../solidworks).
