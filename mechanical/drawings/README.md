# mechanical/drawings

Six A3 sheets as PNG (`AS3-DWG-01` general arrangement … `AS3-DWG-06` pier bracket) and the same set as one PDF,
`AquaSentinel_R3_Drawing_Set.pdf` (open this one first). Generated by `python mechanical/src/drawings.py`, which also needs hidden-line view renders in `drawings/views/` that are not stored in the repository (they are captured from the 3D viewer, see `mechanical/tools/drawing_shots.js`), so the committed PNG/PDF are the reference.
Probe envelopes on the drawings are placeholders until the supplier drawings arrive.
