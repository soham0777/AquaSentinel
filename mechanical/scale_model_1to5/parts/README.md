# parts

Printable STL files of the 1:5 model, one per part in print orientation: `F01`–`F15d` are the float parts, `S01`–`S07` the display stand (the `_A1` files are variants sized for a Bambu Lab A1 bed). Print settings and the build order are in
[`../README.md`](../README.md). Generated by `make_scale_model.py` (and `make_stand_a1.py`) in the parent folder.
