# engineering

The documents that keep the project honest. Read these before you say a number out loud.

| File | What it is |
|---|---|
| [`claims_register.md`](claims_register.md) | every public claim, its value, how we know it (`SIMULATED`, `EXTERNAL`, `DESIGN ESTIMATE`…), and the claims we **no longer make** with the wording to use instead |
| [`jury_QA.md`](jury_QA.md) | prepared answers for jury questions. Q3 still carries v2-era pole numbers: see the team note inside it before quoting |

Rules we keep: say *designed*, not *built*; call the bottle *a sample for the lab*, not "evidence"; quote the pole safety factor
as **2.66** (conservative case), not 4.4; never quote competition grades.

Older specifications are in [`../archive/superseded-docs`](../archive/superseded-docs).
